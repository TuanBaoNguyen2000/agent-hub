- **Tên thư mục của Claude bị trùng:** `src dự án` và `src-dự-án` cùng được mã hoá thành `…-spike15-src-d---n`, vì mọi ký tự không phải chữ cái hay số Latin đều thành `-`. Chỉ đọc tên thư mục thì sẽ lẫn session của hai folder; phải kiểm tra thêm `cwd` trong file.
- **Đường dẫn dài:** Claude cắt tên thư mục ở 200 ký tự rồi thêm `-<hash>` (tổng 207 ký tự). Không tính lại được tên chính xác, nên phải tìm theo tiền tố rồi kiểm tra `cwd`.
- **Unicode:** folder tên NFD trên đĩa thì Claude ghi `cwd` ở dạng NFC (tên thư mục mã hoá cũng từ dạng NFC), còn Codex ghi `cwd` ở dạng NFD. So sánh `cwd = ?` trực tiếp trong SQLite với đường dẫn NFC sẽ không thấy. Phải truy vấn cả hai dạng, hoặc chuẩn hoá trước khi so sánh.
- **Resume:** cả hai CLI ghi tiếp vào file cũ và giữ nguyên id. Codex cập nhật `updated_at_ms`, Claude cập nhật mtime. Sắp xếp theo hai giá trị này cho ra session có hoạt động gần nhất.
- **Thư mục con:** Claude tạo một thư mục project riêng cho mỗi cwd. Muốn tính cả thư mục con thì phải tìm các thư mục project có tiền tố là tên mã hoá của folder, rồi kiểm tra `cwd`.

## Kết luận cho thiết kế

- **Claude:** liệt kê các thư mục trong `projects/` có tiền tố là tên mã hoá của folder (thử cả dạng NFC và NFD). Chỉ lấy các file `*.jsonl` ở cấp đầu. Với mỗi file, đọc tới dòng đầu tiên có `cwd`, so sánh `cwd` sau khi chuẩn hoá NFC, rồi sắp xếp theo mtime.
- **Codex:** đọc bảng `threads` bằng better-sqlite3 ở chế độ `readonly`, chỉ chọn các cột định vị, truy vấn `cwd` ở cả hai dạng Unicode, và kiểm tra `rollout_path` còn tồn tại. Quét dòng `session_meta` là fallback khi bảng không mở được hoặc đổi schema (tên file `state_5` có số phiên bản).
- **Đưa file cho agent đích:**
  - Với Codex, chỉ cần đường dẫn trong lời nhắc.
  - Với Claude, thêm `--add-dir=<thư mục chứa file session>` khi mở CLI. Tab Code của Desktop không nhận tham số này, nên người dùng phải duyệt quyền đọc khi agent hỏi.
- **Kích thước:** một lượt `codex exec` đã tạo file khoảng 120 KB. Lời nhắc nên yêu cầu đọc phần cuối (ví dụ `tail`), không đọc cả file.
- **Giới hạn đọc:** sandbox read-only của Codex đọc được mọi file mà người dùng đọc được. Việc chỉ đọc đúng file transcript dựa vào lời nhắc và sự xác nhận của người dùng (ADR-019 mục 10), không dựa vào sandbox.
