# AgentHub — Agent entrypoint

Entrypoint chung cho coding agents: Codex đọc trực tiếp file này; Claude Code nạp file này qua `@AGENTS.md` trong [CLAUDE.md](CLAUDE.md). Chỉ sửa hướng dẫn tại đây.

Trước khi thay đổi repository, đọc theo thứ tự:

1. [docs/STATUS.md](docs/STATUS.md): trạng thái thực tế và công việc tiếp theo.
2. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md): quy tắc phát triển dùng chung.
3. [docs/TDD.md](docs/TDD.md): phạm vi, kiến trúc, acceptance gates và các ADR.
4. [docs/ROADMAP.md](docs/ROADMAP.md) và [docs/decisions/README.md](docs/decisions/README.md).
5. Tài liệu module hoặc feasibility liên quan đến công việc được giao.

Quy tắc có hiệu lực nằm trong các tài liệu trên; không duy trì một bản sao quy tắc riêng theo provider. Tôn trọng các quyết định đã chốt, ghi rõ bằng chứng kiểm chứng và cập nhật STATUS khi có tiến độ hoặc bàn giao đáng kể.
